# User memory

Search existing notes before relying on remembered preferences or holdings. Store durable preferences in the personal layer and temporary task state in the session layer. Use a role scope for role-specific notes. Include the source and date where useful; distinguish remembered holdings from current account data. Avoid storing secrets. A saved preference does not authorize a later trade or transfer.
