# 缠论 (Chan Theory)

## 这套理论为什么值得谨慎对待

缠论是中文圈独有的价格结构分析体系，由"缠中说禅"在 2006-2008 年博客中系统化。它的吸引力在于声称规则严格、完全客观。它的实际困难在于：

1. **"严格"在纸面上，主观在实现中**。不同实现者（包括《教你炒股票》不同解读注本）对"笔是否成立"、"中枢是否延伸"的判断经常不一致。
2. **规则链很长**：分型 → 笔 → 线段 → 中枢 → 走势类型 → 背驰。每一环都有继承规则，任何一环的判断差异都会传导到最终的买卖点。
3. **多套定义并存**：顶底分型的包含关系处理至少有 3 种规则变体，老笔/新笔之分在不同社群默认不一样。

如果你（agent）在为用户写缠论策略时**凭常识硬编码**这些规则，十有八九写出来的不是用户期望的那一种。**先和用户确认实现流派**再写代码，或者推荐用户先描述他自己的规则。

## 名词的最低限度共识

下面这些是大多数实现大体一致的最低限度。在用户没给出具体流派前，只能在这个共识层讨论：

| 术语 | 大体含义 |
|---|---|
| **K 线包含关系** | 一根 K 线的高低点完全包含相邻 K 线的高低点。缠论要求把这种包含先合并掉再分笔 |
| **分型** | 三根 K 线构成的局部顶（中间最高）或底（中间最低） |
| **笔** | 相邻顶分型与底分型（或反之）之间的连接。中间间隔的 K 线数要达到流派规定的最小值（常见是至少 5 根独立 K 线） |
| **线段** | 至少三笔构成，且方向一致的笔序列。线段的破坏至少需要一个反向线段 |
| **中枢** | 至少三个连续次级别走势类型的重叠区间。常简化为"最近三笔的价格重叠区" |
| **走势类型** | 趋势 / 盘整。有个数中枢的差异（趋势至少两个同级别中枢） |
| **一买 / 一卖** | 趋势背驰后出现的第一个反向信号点 |
| **二买 / 二卖** | 一买/卖之后不创新低/高的回撤点 |
| **三买 / 三卖** | 突破中枢后回踩不破的确认点 |
| **背驰** | 走势动能减弱，常用 MACD 面积或者最后一个线段的幅度比较来近似 |

## 给 agent 的写作建议

**Remember**: 这不是一个文档就写完的策略家族。

- 用户提"缠论"先问 **流派**（原版 / 简化版 / 中证版）
- 给定流派后，**先实现一个原子操作**并回测，例如"只识别顶底分型，不构笔"，作为 sanity check
- 笔/线段/中枢逐级往上叠，每叠一级回测一次，不要一次性把全部五层堆上去
- 任何"一买/二买/三买"信号都要追问"在哪个中枢、什么时间级别"。跨级别信号不可用本引擎回测（我们单级别）

## 在本引擎中的可行性

| 子结构 | 能否实现 |
|---|---|
| 顶底分型识别（含包含处理） | 可以，~80 行 |
| 单笔识别（最少 5 根 K 线间隔） | 可以，~150 行 |
| 线段识别 | 可以但已经开始复杂，~300 行 |
| 三笔中枢（最简版） | 可以，~400 行 |
| 多级别中枢（本级别 + 次级别） | 引擎不支持，单级别数据 |
| 背驰判定 | 取决于流派；MACD 面积近似可做 |

**No code example in this build.** 建议用户直接用更简单的等价概念（SMC 的 BOS/ChoCH、Ichimoku、或者 swing high/low 突破）做初始回测，等缠论的具体流派清晰后再投入实现。

## 给用户的诚实声明

如果用户在 chat 中说"帮我写一个缠论策略回测"，agent 应当：

1. 承认缠论实现流派众多，反问用户具体流派
2. 说明当前引擎不支持多级别（本级别 + 次级别联立）
3. 提示用户概念验证阶段可以先做"顶底分型 + 单笔"这个最简子集
4. 不要凭脑补生成"标准缠论代码"交付给用户——那是给用户埋雷
